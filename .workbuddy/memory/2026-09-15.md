## fantasy-blueprint（奇幻造物实现蓝图）仓库

- 项目性质：纯静态 SPA，hash 路由，无后端。入口 `index.html`，数据层 `js/data/*.js`，视图层 `js/views/*.js`，`js/router.js` + `js/app.js`。
- 部署：GitHub Pages，从 `main` 分支根目录发布，地址 `https://blackinkvc.github.io/fantasy-blueprint/`。
- **关键坑（已踩并修复）**：数据文件（`js/data/techs.js`/`works.js`/`tree-template.js`）里的中文文本若内嵌 ASCII 双引号 `"`，会提前截断字符串 → 整个文件解析失败 → `TECHS`/`WORKS`/`TREE_BRANCHES` 等全局 undefined → 所有视图渲染空白。
  - 修复方式：用字符串状态机把"两侧被内容包围的内嵌引号"替换为全角 `“”`（真实闭引号判定 = 其后紧接 `, : } ] )` 或行尾）。
  - 验证：`node --check` 全过 + 用 DOM 桩跑全部 10 条路由确认 `app.innerHTML` 非空。
  - **以后编辑数据文件务必用全角引号 `“”` 或转义，别用 ASCII `"`。**
